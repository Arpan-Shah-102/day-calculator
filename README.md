# Day Calculator
A visual chart that you can edit and modify to see where your time each day goes or if you need to manage your schedule.

### Features
- Custom Labeling
  - Label Each Block with it's own tag
- Custom Colors
  - Change the colors of each label
- Different Time Settings
  - Chose how many intervals there should be
- Custom Labeling
  - Create Custom Labels
- Deleting Labels
  - Delete any label you want
- Clear Chart
  - Clear the chart at any moment.
- Label Key Grid
  - Shows you all of the different labels and you can use them by clicking on them.
- Mobile UI Support
  - View this even on mobile with no compromise to functionality
